# CodexShell

**CodexShell** puts Codex CLI and the tools you choose in Docker, ready to launch in a couple of steps. Isolated environment, firewall on by default, zero clutter on your host — just mount your project folders and start coding.

## Requirements

[Docker Desktop](https://www.docker.com/products/docker-desktop) (macOS) or [Docker Engine](https://docs.docker.com/engine) (Linux) — **installed and running** before you start.

## Installation

```bash
curl -fsSL https://raw.githubusercontent.com/boboshko/codexshell/master/install.sh | bash
```

## Usage

Go into the CodexShell folder:

```bash
cd codexshell
```

Run the shell:

```bash
./start.sh
```
